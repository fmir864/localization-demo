# Localization Demo

This is a simple demo project to show how to implement localization in ASP.NET Core Razor Pages.
Following are the references used to create this project:

1. https://learn.microsoft.com/en-us/aspnet/core/fundamentals/localization?view=aspnetcore-8.0#resource-files

2. https://darkopecnik.com/blog/1/localization-with-language-selector-in-razor-pages

3. https://www.mikesdotnetting.com/article/345/localisation-in-asp-net-core-razor-pages-cultures
